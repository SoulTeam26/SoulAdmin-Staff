# Soul Admin — Staff Panel

Single-file staff panel for the Soul Team. **`index.html` is the whole panel** —
the Cape Builder and Shield Builder are embedded inside it (no extra files needed).

- Deploy this repo as its own Vercel project (import → Deploy).
- Staff members sign in with the credentials the owner approved for them.
- Builder access is granted per staff member by the owner (saved at `staff/{key}/tools`).

Owner (full) panel lives in [SoulTeam26/SoulAdmin](https://github.com/SoulTeam26/SoulAdmin).
