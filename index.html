Firebase Security Rules

The admin panel connects with no Firebase Auth token, and the website store needs to create orders/tickets/unlock items anonymously. So the database must stay open to reads and writes everywhere. Copy these rules into Firebase Console > Realtime Database > Rules to make both the site and the admin panel work.

{ "rules": { ".read": true, ".write": true, "players": { ".indexOn": ["name"] }, "posts": { ".indexOn": ["timestamp"] } } }
WHY IT MUST BE OPEN: The admin panel has no login, so Firebase cannot tell an admin write from a public one. Locking nodes like capes/catalog, capes/codes, posts, team, soul_versions, etc. to false (or to auth != null) makes the ENTIRE admin panel stop working.

If the store or admin breaks with a permission error after a rule change, paste the exact rules above into Firebase Console and Publish.
